# Methodology

1. Build the 33/11 kV network in ETAP.
2. Enter actual equipment ratings and electrical parameters.
3. Perform load-flow analysis.
4. Perform short-circuit analysis.
5. Define fault scenarios.
6. Configure overcurrent and earth-fault relays.
7. Run protection coordination.
8. Verify circuit-breaker operation.
9. Prepare the electrical drawings in AutoCAD Electrical.
10. Export verified results and screenshots.
11. Document conclusions based only on the actual simulation.
